# 🎮 Python Adventure RPG

A Python-based command-line Role-Playing Game where players choose a character, explore the game world, encounter enemies, collect rewards, and participate in battles.

## 🚀 Features

- Choose between Knight, Archer, and Mage
- Character statistics including health, attack, gold, XP, and level
- Random exploration events
- Random enemy encounters
- Battle system with attack and run options
- Different enemy types with different stats
- Gold and XP rewards after defeating enemies
- Player statistics display
- Game-over system

## 🛠️ Technologies Used

- Python
- Random module

## 📚 Concepts Demonstrated

- Functions
- Dictionaries
- Loops
- Conditional statements
- User input
- Random number generation
- String formatting
- Game logic
- Basic exception/error handling

## 🎮 Character Classes

| Character | Health | Attack |
|-----------|--------|--------|
| Knight | 120 | 20 |
| Archer | 100 | 25 |
| Mage | 80 | 35 |

## 👾 Enemies

The game randomly generates different enemies:

- Goblin
- Skeleton
- Dragon

Each enemy has different health, attack, gold, and XP values.
